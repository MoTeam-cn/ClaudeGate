# 已知风险

用之前请读完这一页。

## 条款风险

Anthropic 在 2026-02-19 更新了文档，**禁止第三方使用 Free / Pro / Max 订阅的 OAuth 令牌
代路由请求**，要求改用 Console API Key。

本项目号池默认走订阅 OAuth，属于条款灰色地带。**由使用者自担后果。**

要规避的话，把账号类型改成 Console API Key（面板里可以导入），
代价是按量计费、没有订阅额度。

## 账号指纹

`metadata.user_id` 里嵌着一个跨会话恒定的 `device_id`（64 位十六进制）：

```json
{"device_id":"a9560f...","account_uuid":"","session_id":"..."}
```

**换出口 IP 带不走它。** 网关当前原样透传。

如果哪天号被标记，光换落地机不够 —— 需要改写这个字段。但那会改变上游看到的账号画像，
属于独立决策，默认不做。

## 版本要求

- Node 22.5–23.3 跑 `node:sqlite` 需要 `--experimental-sqlite`，23.4+ 免标志
- 项目用了原生 TypeScript 直跑，需要 Node **22.6+**
- Docker 镜像用的是 Node 24，没有这个问题

## 隐写检测的维护

隐写规则基于已知机制（2.1.91–2.1.196 的行为）。**上游若改手法，需要同步更新**
`src/security/stego.ts` 的规则表。

当前规则：

| 码位 | 判定位置 |
|---|---|
| `U+2019` | 只在日期行位置（避免误伤散文里正常的排版撇号） |
| `U+02BC` / `U+02B9` | 全局 |
| 斜杠日期分隔符 | 日期行位置 |

## 安全建议

| 事项 | 建议 |
|---|---|
| 面板登录密钥 | 首次启动自动派发，日志里打印一次，**之后不再打印**。那段日志要立刻收好或从日志系统里删掉。盘上只有 scrypt 哈希，主密钥在 `data/admin.json`，两个都要进备份 |
| `ADMIN_TOKEN` | 逃生口。显式设了它就完全接管鉴权（不派发不打印）。只有在需要绕过自动派发时才设 |
| `SECRET` | 留空会自动生成到 `data/secret`；多实例部署要显式指定同一个值 |
| 数据库 | 里面存着账号凭据与 API Key 的 sha256，`data` 目录不要提交进仓库、注意备份权限 |
| `TRUST_PROXY` | 只有在反代后面才设 true。直接暴露时设 true 会让客户端 IP 可被伪造 |
| TLS | 网关本身不做 TLS，请由 Caddy / Nginx 终止 |
| 面板 | 登录密钥走 `x-admin-token` 头、只存浏览器 localStorage，不进 URL。盘上只有 scrypt 哈希，明文只在首次派发时打印一次。用 curl 时才用 `?key=`，那样会留在 shell 历史里 |

## 能力边界

- **不保证不被封号。** 它做的是「把明显的标记收干净 + 出口 IP 稳定」，
  风控是多维的，这里覆盖不了全部
- **不做内容审查或改写。** 只处理隐写标记这类结构性问题
- **不代理非 Anthropic 上游。** 上游地址可以改，但协议按 Anthropic 与 OpenAI 两套实现
- **单进程。** 不启 cluster，避免多进程争 SQLite 写锁

## 已知缺口

- 节点级（多实例）没有内置的共享状态，多实例部署需要自己解决数据库共享
- 隐写检测只覆盖已知的日期行手法
- `device_id` 未做改写（见上）
